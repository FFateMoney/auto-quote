# 自动报价系统操作手册

## 1. 手册说明

本手册面向报价人员和目录维护人员，以系统前端页面为操作入口，说明如何创建报价、核对和修改结果、切换设备、导出报价单，以及维护测试项目和设备能力。

系统左侧导航栏包含三个主要入口：

- 系统标志：进入“创建报价”页面；
- 报表图标：返回当前报价结果页面；
- 设置图标：进入数据库管理页面。

报价任务创建后，页面会自动进入运行结果页。需要重新提交新需求时，点击页面右上方“返回重新上传”。

## 2. 创建报价

### 2.1 上传报价需求文件

1. 进入“创建报价”页面。
2. 选择“上传需求文档”。
3. 将一个报价需求文档拖入“报价需求”区域，或者点击该区域选择文件。
4. 确认页面已显示正确的文件名。

报价需求文档只能有一个。一个文档中可以包含多个试验需求，系统会将识别出的每项独立报价分别展示。

当前可选择的常用格式包括：Word、Excel、PDF、TXT、Markdown、CSV，以及 PNG、JPG、BMP、WebP、TIFF 等图片格式。

### 2.2 粘贴报价需求文本

1. 在创建报价页选择“粘贴需求文本”。
2. 在文本框中输入或粘贴试验项目、标准号、样品信息、试验条件和计价数量等内容。
3. 检查右下角字符数量，文本上限为 100000 个字符。

系统会把这段文本作为本次报价需求提交，后续操作与上传文件相同。

### 2.3 添加参考文件

参考文件用于补充报价需求中未完整说明的标准、客户附件、试验条件、样品资料或图片。

添加方式：

- 点击“添加文件”，可一次选择多个文件；
- 将文件拖入参考文件区域；
- 点击文件右侧的移除图标，取消不需要提交的文件。

报价需求文件与参考文件的角色不同。主需求只放在“报价需求”区域，其他补充资料放在“参考文件”区域。

### 2.4 添加样品信息

1. 点击参考文件区域上方的“添加样品信息”。
2. 填写“样品数量”。
3. 直接填写“规格 (m3)”，或者完整填写长度、宽度、高度。
4. 长、宽、高全部填写后，系统会自动计算规格立方米。
5. 点击“添加到参考文件”。

添加成功后，参考文件列表会出现“样品信息.txt”。该文件会随本次报价一起提交。长、宽、高的输入单位为毫米，规格单位为立方米。

### 2.5 开始报价

确认需求文件或需求文本，以及所有参考资料无误后，点击“开始智能报价”。

系统进入报价结果页并自动更新运行状态。报价完成后会直接展示报价内容，不需要再次点击“查看结果”。处理时间取决于文件数量、文件复杂度和需要识别的独立试验数量。

## 3. 查看报价结果

### 3.1 查看运行状态

结果页顶部显示当前运行状态。系统会自动刷新处理进度；也可以点击“刷新状态”立即查询。

常见状态含义：

| 页面状态 | 含义 |
|---|---|
| 正在处理 | 系统正在读取文件并生成报价。 |
| 报价已完成 | 已生成报价项，可查看、修改和导出。 |
| 提交未通过 | 报价表格式未通过处理，需要维护人员查看运行信息。 |
| 运行失败 | Agent 或模型调用未正常完成，需要维护人员排查。 |

### 3.2 切换报价项

一个需求中识别出多个独立报价时，页面上方显示报价切换卡片。点击卡片即可查看对应报价，页面不会把多个报价表连续堆叠展示。

每个报价项分别展示：

- 固定字段：原始试验类型、标准类型、测试项目、标准号、标准章节、规格、计价方式、计价数量、样品数量和尺寸；
- 专有字段：当前试验项目需要关注的温湿度、振动、水流、辐照、负载等能力要求；
- 报价：基本金、单价、计价方式、计价数量和总价；
- 匹配设备表：满足当前试验条件的设备及其能力。

值显示为 `null` 表示输入资料中未取得明确内容。

### 3.3 核对重点

建议在导出前至少核对以下内容：

1. 原始试验类型是否对应需求文件中的项目；
2. 标准类型、测试项目和规格是否匹配；
3. 标准号和标准章节是否正确；
4. 计价方式和计价数量是否正确，时长计价的数量单位为小时；
5. 样品数量与样品尺寸是否正确；
6. 专有试验条件是否完整；
7. 当前选中设备是否合适；
8. 基本金、单价和总价是否符合预期。

## 4. 修改报价

### 4.1 修改字段

1. 在当前报价的“固定字段”或“专有字段”区域找到需要修改的字段。
2. 点击字段卡片中的“编辑”。
3. 输入或选择正确值。
4. 点击“保存”。

标准类型、测试项目、规格和计价方式使用系统目录中的下拉选项。修改标准类型后，测试项目和规格选项会随之变化。其他数值或文本字段可直接输入；清空后保存表示将该值设为空。

每次保存都会形成新的报价版本。当前页面、设备筛选、导出和保存至历史报价库均以最近一次保存的内容为准。

### 4.2 修改规格

规格卡片内同时显示样品长度、宽度和高度作为参考。点击“编辑”后，从当前标准类型和测试项目支持的规格中选择。

更换规格可能同时切换测试项目记录、计价方式、基本金、单价和适配设备。保存后应重新核对报价区与设备表。

### 4.3 选择设备

匹配设备表按功耗从低到高排列，默认设备标记为“当前选中”。

需要改用其他设备时，点击该设备右侧的“选用并重新报价”。系统会使用当前报价字段重新确认该设备是否可用，并更新当前报价快照。

如果设备表显示“当前条件下没有可用设备”，先检查标准类型、测试项目、规格和专有字段。修正字段后，系统会重新筛选设备。

### 4.4 基本金归零

在“报价调整”区域使用“基本金归0”开关：

- 开启：本次运行中的全部报价项基本金设为 0，并重新计算总价；
- 关闭：恢复各测试项目原有的基本金，并重新计算总价。

该开关作用于本次运行的全部报价项。切换后应核对每项报价的总价。

## 5. 导出和保存

### 5.1 下载源文件

点击“下载源文件”可下载本次报价的原始需求文件。该按钮不会下载报价结果。

### 5.2 全部导出

点击“全部导出”，将本次运行中所有可报价项目导出到同一份 Word 报价单，每个报价项目占一行。

### 5.3 单个导出

先在报价切换区选择目标报价，再点击“单个导出”。生成的 Word 报价单只包含当前选中的报价项。

导出使用当前人工修改后的最新版本。总价未能计算的项目不会进入报价单，因此导出前需要确认测试项目、基本金、单价和计价数量均已正确显示。

### 5.4 保存至历史报价库

完成核对和人工修改后，点击“保存至历史报价库”。系统会将本次运行的每个当前报价项保存为一条历史记录，并提示成功保存的数量。

历史报价用于后续相同标准条件的报价信息复用。缓存分组、可复用字段和查询顺序见[技术文档](./技术文档.md)。

## 6. 查询历史报价运行

1. 返回“创建报价”页面。
2. 打开“报价历史查询”下拉列表。
3. 选择一个历史运行名称。
4. 系统进入该运行的报价结果页面。

这里查询的是以往的报价运行及其结果。进入历史运行后，仍可查看、修改、选择设备和重新导出。

## 7. 数据库管理

点击左侧设置图标进入数据库管理页。该页面用于维护测试项目和设备能力，会直接影响后续项目匹配、动态字段、设备筛选和报价金额。

### 7.1 测试项目表

测试项目按“标准类型”分组固定展开。每一行测试项目包含测试项目名称、最大规格、计价方式、基本金、单价、适配设备集合和别名。

#### 新增标准类型

1. 点击不属于任何现有标准类型分组的“添加标准类型”。
2. 输入新的标准类型名称。
3. 同时填写该标准类型下第一条测试项目，包括测试项目、最大规格、计价方式、基本金、单价和适配设备。
4. 保存后，页面新增一个标准类型分组，并显示刚创建的测试项目。

标准类型当前以测试项目分组存在，因此新增标准类型时必须同时建立第一条测试项目。

#### 在现有标准类型下添加测试项目

1. 找到目标标准类型。
2. 点击该分组右侧“添加测试项目”。
3. 标准类型保持固定，输入测试项目和其他报价字段。
4. 适配设备只能从设备能力表中已有设备选择。
5. 点击保存。

最大规格表示该项目记录支持的规格上限或规格类别，例如 `1`、`2.4`、`振动台` 或 `none`。

#### 修改或删除测试项目

- 点击编辑图标，修改测试项目、规格、计价方式、价格和适配设备；
- 点击删除图标后，该项目进入回收站，不会立即从数据库物理移除；
- 在回收站中点击“恢复”，项目回到原有标准类型分组。

#### 管理测试项目别名

1. 点击测试项目名称。
2. 在“管理别名”窗口输入别名并点击“添加”。
3. 可删除不再使用的别名。
4. 点击“保存”提交本次修改。

别名帮助系统将需求文件中的客户叫法映射到标准测试项目。名称映射机制与 Agent 查询规则见[技术文档](./技术文档.md)。

### 7.2 设备能力表

设备能力表每行代表一台设备，展示设备编号及温度、湿度、尺寸、流量、频率、加速度、位移、负载和功耗等能力。

- 点击新增按钮可创建设备；
- 点击编辑图标可修改设备编号和能力值；
- 不存在或未知的能力保持为空；
- 点击删除图标后设备进入回收站；
- 在回收站中点击“恢复”可重新启用设备。

设备能力修改后，系统会更新受影响测试项目的专有字段集合。设备字段与比较协议见[技术文档](./技术文档.md)。

## 8. 新增功能操作指南

以下功能已纳入当前操作流程：

| 新增功能 | 操作入口 | 用途 |
|---|---|---|
| 多格式、多参考文件报价 | 创建报价页 | 一个主需求可附加多个标准、图片和客户附件。 |
| 粘贴文本报价 | 创建报价页的“粘贴需求文本” | 将临时需求文字直接作为报价输入。 |
| 添加样品信息 | 参考文件区域 | 单独补充样品数量、规格和长宽高。 |
| 动态专有字段 | 报价详情页 | 根据测试项目和设备能力展示相应试验参数。 |
| 人工修改快照 | 字段卡片“编辑” | 每次保存保留一个新版本，供展示和导出使用。 |
| 设备重选 | 匹配设备表 | 在可用设备中人工指定设备并重新报价。 |
| 基本金归零 | 运行操作的“报价调整” | 批量切换本次报价是否收取基本金。 |
| 历史报价保存与复用 | “保存至历史报价库” | 保存审核后的报价，并为后续标准条件补全提供参考。 |
| 测试项目别名 | 设置页点击测试项目名称 | 维护客户叫法与标准项目之间的名称映射。 |
| 目录软删除和恢复 | 设置页回收站 | 暂停使用并恢复测试项目或设备。 |

本节只说明前端操作入口。动态表单生成、快照覆盖关系、历史缓存规则、设备筛选和计价机制见[技术文档](./技术文档.md)。

## 9. 常见问题

| 现象 | 处理方式 |
|---|---|
| “开始智能报价”不可点击 | 检查是否已上传一个需求文件，或是否已在文本框输入内容。 |
| 报价完成但没有显示结果 | 点击“刷新状态”；仍无结果时记录运行名称并联系维护人员。 |
| 某个字段显示 `null` | 输入资料未取得明确值，可使用字段卡片的“编辑”人工补充。 |
| 总价为空 | 检查是否已选择有效测试项目，以及计价数量是否为空。 |
| 没有可用设备 | 检查测试项目、规格和专有字段是否正确，再保存修改以重新筛选。 |
| 导出按钮失败 | 确认当前项目已有总价；全部项目均无总价时无法导出。 |
| 找不到标准类型或测试项目选项 | 请由目录维护人员先在设置页新增对应项目。 |
| 参考资料未生效 | 确认文件已显示在参考文件列表中，再重新创建报价。 |

## 10. 操作注意事项

- 报价需求文档只能上传一个，其他资料应作为参考文件添加；
- 上传前确认文件未损坏，Excel、Word 文件应能在本机正常打开；
- 自动结果应在导出前进行人工核对；
- 修改标准类型、测试项目或规格后，应重新检查设备与价格；
- “保存至历史报价库”应在报价内容确认完成后执行；
- 目录管理会影响后续全部报价，价格和设备调整应由授权人员操作。
